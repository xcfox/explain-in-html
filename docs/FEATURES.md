# 功能清单（相对原实现已有能力，不扩大范围）

对照原 design-viz 的 SQL 表结构页与 GraphQL 接口页。本技能在 Vue 3 声明式形态下保留这些能力，不静默缩水，也不发明通用内容解释器。

## GraphQL 接口页

- 按域分组列出操作与类型；搜索操作名 / 描述 / 类型名；无匹配时空态
- 搜索时域分组强制展开；折叠状态可持久化
- 操作签名（含参数默认值与注释）以 token 高亮展示，类型名可跳转
- 返回类型就地展开 SDL；其余类型以芯片列出（类型 / 输入分组）
- 类型详情：SDL、引用、使用此类型的操作
- 悬停预览类型摘要（截断 SDL + 描述）
- 右侧 tabs 打开 / 切换 / 关闭类型详情
- 侧栏宽度拖拽并记忆；视口变窄时钳制宽度
- 当视口不足以同时放下最小详情栏（320px）与最小主栏（400px）时，详情改为覆盖层加遮罩，避免主栏被挤到不可用宽度
- 跟随系统暗色色板（CSS `prefers-color-scheme`）
- SDL 中的类型链接：若本页已有锚点则跳转，否则打开详情 tab（⌘/Ctrl 点击亦打开 tab）

## SQL 表结构页

- 域分组侧栏导航
- 搜索表名 / 注释 / 域名**只过滤左侧导航**，主栏仍按域展示全部表卡片（与原实现一致；例如输入 `projects` 只会收窄导航，正文卡片不会被筛掉）
- 列表主栏按域分段展示表卡片
- 实体 / 弱实体 / 关系表（assoc）不同展示：列、关系、端点、关联属性、索引、TS 类型
- 关系种类：n:1、1:1、自关系、N:M（折叠 via）、nary、标识关系、引用（audit/ref）
- 行内 TypeScript 声明高亮与具名类型悬停预览
- 表悬停预览（列与约束）
- 窄屏抽屉（菜单按钮 + 遮罩）；宽屏三栏，塞不下时收起侧栏
- 右侧 tabs 详情（宽屏）；窄屏改为滚动到列表卡片
- 侧栏宽度拖拽并记忆
- 跟随系统暗色；自动取色表/域在系统换肤时重染
- 列表滚动与当前表同步；hash 定位表名
- 从卡片或关系跳到关系图并聚焦节点

## 关系图

- 列表 / 关系图模式切换
- 节点：实体圆角矩形、弱实体双线框、未折叠 assoc / nary via 为菱形
- N:M 关系表折叠为实体之间的边（标签为 via，属性数量徽标）
- 边型：owner 实线、ref 虚线（默认隐藏，可开「引用边」）、self 回环、ident 加粗；两端 1 / N / 0..1
- 域 hull 分组（可开关）与图例（点击聚焦域）
- 平移、滚轮 / 触控板缩放（指针为心）、+/−、适应、双击空白适应
- 节点拖拽只更新坐标；位置按模式名写入本地存储并在刷新后恢复；重排清除记忆并重新布局
- 悬停高亮邻接并显示边说明；点击节点或边打开详情（窄屏回到列表）
- 图例、工具栏、点阵底图随视口变换

## 交付形态

- 两个互相独立的单文件 HTML；运行依赖固定 Vue 3.5.13 完整生产 CDN，不是离线自包含
- 用户打开产物无需 npm / Node / Bun
- 可选作者工具 `node lib/render-api.js` / `node lib/render-erd.js` 解析并组装
